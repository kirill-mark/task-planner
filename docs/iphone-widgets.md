# MARK — виджеты iPhone

## Реализовано

Один нативный WidgetKit extension с двумя виджетами «Сегодня в MARK» и «План на день»:

- Маленький виджет главного экрана: ближайшая задача сегодня, время, прогресс дня.
- Средний виджет: первые три открытые задачи на сегодня, время, прогресс, количество остальных.
- Прямоугольный виджет экрана блокировки: ближайшая задача и время.
- Круглый виджет экрана блокировки: число оставшихся задач.
- Строка над часами: ближайшая задача и время.
- «План на день», большой: до семи открытых задач, время, прогресс и количество остальных. Поддерживает главный экран и экран «Сегодня».
- «План на день», экран блокировки: до трёх задач в компактной прямоугольной карточке и счётчик дополнительных задач.

Тап по задаче в большом/среднем виджете открывает её редактор в MARK. Тап по счётчику/заголовку, карточке «План на день» на блокировке или ссылке «Открыть весь день» открывает список «Сегодня». Ссылка проверяется по текущему аккаунту. Холодный запуск сохраняет ссылку до загрузки сессии и задач.

## Данные и обновления

`group.com.kinomark.mark` соединяет только приложение MARK и его расширение. В атомарный локальный JSON передаются названия, ID, время и дневные счётчики — без заметок и токенов. Файл защищён до первого разблокирования после перезапуска. Представления помечены `privacySensitive`, iOS применяет пользовательские настройки отображения данных на заблокированном экране.

Данные обновляются при загрузке/изменении задач, смене аккаунта/часового пояса и возвращении в MARK. При выходе/смене аккаунта прежний список очищается. При старте того же аккаунта сохраняется офлайн-кэш, пока IndexedDB не готова. Обновления сериализованы, чтобы старый аккаунт не перезаписал новый.

В снимке восемь календарных дней в часовом поясе аккаунта. WidgetKit переключает день в полночь и ближайшую задачу по временной шкале. Будущее время задачи имеет приоритет, затем дело без времени, затем оставшееся пропущенное дело сегодня. Выполненные входят в прогресс, но скрыты из открытого списка. Старые просроченные и корзина не отображаются. План и дедлайн в один день считаются один раз.

iOS управляет временем реального обновления. Изменения с другого устройства попадут в виджет после синхронизации MARK на этом iPhone. Расширение самостоятельно не входит в Supabase. По истечении подготовленных восьми дней просит открыть MARK. На день сохраняются первые 100 открытых задач с названиями до 120 символов; счётчики учитывают полный день.

## Добавить

Главный экран: удержать свободное место → «Изменить» → «Добавить виджет» → MARK → «Сегодня в MARK» маленький/средний или «План на день» большой.

Экран блокировки: удержать экран → «Настроить» → «Экран блокировки» → область под часами → MARK → прямоугольный/круглый «Сегодня» или прямоугольный «План на день». Строка над часами также поддерживается. Нужна iOS 16+, основной MARK поддерживает iOS 15.4+.

Большой список до разблокировки: добавить «План на день» на экран «Сегодня» (свайп вправо с главного экрана, удержать пустое место, «Изменить» → «Добавить виджет» → MARK). С экрана блокировки также можно свайпнуть вправо. Доступ зависит от пользовательских настроек iOS: «Настройки» → «Face ID и код-пароль» → доступ с блокировки → «Сегодня и Поиск».

Под часами iOS поддерживает только accessory-размеры, большое системное семейство туда добавить нельзя. Инструкции Apple: https://support.apple.com/en-gb/118610 и https://developer.apple.com/design/human-interface-guidelines/widgets.

## Проверки

- `npm run test:widget`: снимок, часовые пояса, дедлайны, прогресс, очистка при смене аккаунта, повтор после ошибки, безопасный переход по ссылке.
- `npm run test:widget:swift`: выбор ближайшей задачи, смена дня, Codable, URL и пустой снимок в общей Swift-модели.
- Xcode: signed build App + embedded MARKWidgetExtension; одинаковый App Group в подписанных entitlements обоих продуктов.
- Физический iPhone: пользователь подтвердил наличие виджетов главного экрана и блокировки. Расширенный «План на день» установлен в следующей сборке; внешний вид списка, переход и обновление требуют отдельного подтверждения устройства.

## Помощник на экране блокировки — 10 октября

Отдельный «Помощник MARK»: круглый, прямоугольный и строка над часами (iOS 16+). Иконка sparkles, без личных названий задач. Ссылка mark://widget?user=…&screen=assistant открывает чат текущего аккаунта. ИИ-запрос и диктовка автоматически не запускаются. Ссылка другого аккаунта не открывает его данные.

Пользователь подтвердил на физическом iPhone: «Да, открылся помощник».
