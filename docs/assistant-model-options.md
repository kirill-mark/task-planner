## Предложение

Сначала сравнить GPT-6.1 Sol и Claude Sonnet 5.5 с текущей моделью на 12–20 одинаковых обезличенных сценариях: близкий дедлайн против высокого приоритета, фиксированный созвон вечером, равные задачи без сроков, неуказанная длительность, зависимости только из описания, память и новая беседа, явное изменение с подтверждением. Gemini 3.8 Flash — дополнительный кандидат при желании сравнить стоимость.

Оценивать: корректные даты и факты, объяснение «почему эта раньше другой», отсутствие выдуманных последствий, короткие абзацы и пункты, нужный уточняющий вопрос, корректный JSON действий, задержку и стоимость по фактическому usage. Бренд модели сам по себе не заменяет такую проверку.

## Что потребуется для реального подключения

Аккаунт провайдера с доступом API в поддерживаемом регионе, доступный способ оплаты и согласованный месячный бюджет. Ключ хранится только в Supabase Edge Function secrets; его нельзя встраивать в iPhone или присылать в обычный чат. UI MARK сохраняется, меняется серверный адаптер ответа. Нужны одинаковая проверка JSON и действий, таймауты, обработка лимитов и обновлённый текст согласия с конкретным провайдером. Подписка на потребительский чат не является заменой API-биллинга. Ни один новый провайдер сейчас не подключён, реальные данные ему не отправлялись.

В бесплатном Gemini API содержимое может использоваться для улучшения продуктов Google; на платном тарифе — нет согласно таблице условий. Перед использованием необходимо проверить актуальные условия аккаунта и соответствующие исключения.
