# Mark, концепция C — материалы для вёрстки

Концепция C выбрана основой мобильной версии Mark: спокойная основа пакета B и отдельные решения из концепции B (заметная главная задача, явное поле ввода, лёгкие разделители). Сравнение направлений завершено.

## Где что лежит

| Что | Где |
|---|---|
| Макеты (холст, 120 экранов, обе темы, 360 px, крупный текст) | https://claude.ai/artifact/Sqy8Tcbs7kHMnSURWSSwGw — доступ только у владельца, делиться через «Поделиться» на холсте |
| Исходники макетов | `design/c/` — `ds.py` (система оформления), `s_*.py` (экраны по разделам), `project/` (собранные экраны) |

| Иконки | `design/c/icons/*.svg` (24 × 24, линия 1,8, цвет — `currentColor`) |
| Знак и иконка приложения | `design/brand/` |

## Как пересобрать

```bash
python3 design/c/build.py
python3 design/c/export.py
```

`build.py` пишет экраны и `project/canvas.json`; `export.py` — `tokens.json`, иконки, `tokens.md` и `behavior.md`. Макеты меняются только в `design/c/*.py`, файлы в `project/` руками не правятся.

## Основные сценарии прототипа

1. **Главное на сегодня:** H01 → название главной задачи → E01 → «…» → E03.
2. **Записать по названию:** H01 → «+» → C01 → C02 → «Добавить» → C13 → «Отменить».
3. **Длинная задача на завтра с напоминанием:** C03 → «Без даты» → D01 → «Завтра» → C05 → «Напомнить» → D06 → C06.
4. **Перенести время, не трогая срок:** E01 → «Когда сделать» → E02.
5. **Выполнить и отменить:** H01 → отметка → H10 → «Отменить».
6. **Найти задачу:** T01 → лупа → T06.
7. **Проект и задача в нём:** T04 → проект → P04 → «…» → P09; P01 → «Новый проект» → P03; P04 → «+» → C07.
8. **Разобрать входящую без даты и проекта:** H01 → «Входящие · 4» → T09 → «Разобрать» → T11.
9. **Помощник:** H01 → «Обсудить план» → A01 → A02 → A03; A06 → «Применить» → A07 → A08 → «Отменить изменения» → A12.
10. **Две версии:** H08 → «Сравнить» → H09.

## Порядок работ

1. Владелец просматривает макеты и отвечает на открытые вопросы в `scope.md`.
2. Вёрстка концепции C в тестовой сборке: сначала система оформления и название «Mark», затем главная и форма, затем остальные разделы.
3. Перенос групп в проекты на копии тестовых данных, затем проверка на iPhone.
4. Тест с пятью пользователями по `usability-test.md`, список проблем с приоритетами, исправление критичных.
