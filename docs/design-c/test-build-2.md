# Тестовая сборка 2 — задачи и проекты

24 октября 2026. Продолжение сборки 1 (`test-build-1.md`). Данные на сервере не переносятся: проекты — это прежние группы под новым названием.

## Что вошло

- **Экран «Задачи» на телефоне по макетам T01–T17.** Заголовок с числом открытых задач, поиск и выбор вида; фильтры «Все», «Сегодня», «Входящие» и лист «Показать»: ближайшие 7 дней, без даты, просроченные, выполненные, корзина, проекты.
- **«Все» по датам:** Просрочено, Сегодня (со ссылкой «Выполнено сегодня»), Завтра, Позже, С прошлых дней, Без даты.
- **Вид «По проектам»** — до трёх задач каждого проекта и «Ещё N», затем «Без проекта». Выбранный вид запоминается на телефоне.
- **Поиск** по названиям и описаниям, включая выполненные; если ничего не нашлось — «Создать задачу «…»».
- **Просроченные** — по прошедшему сроку, с «На сегодня» и «Перенести…»; отдельно «Не сделано в запланированный день».
- **Проекты по макетам P01–P10:** список с поиском и счётчиками, пустое состояние, создание (только название), просмотр проекта по датам, «Задача в этот проект» и «+» внутри проекта подставляют проект, переименование, удаление.
- **Удаление проекта** удаляет только проект: задачи остаются без проекта. Если у задачи нет и даты, она окажется во «Входящих».
- Название проекта должно быть уникальным: два проекта с одним именем создать нельзя. Уже существующие повторы не объединяются и подписаны разделом.
- Кнопки «Разделы и группы» на телефоне больше нет.

## Что проверить

1. «Задачи» → «Все»: группы по датам, метки сроков.
2. Значок слоёв → «По проектам» → закрыть и открыть приложение — вид сохранился.
3. Лупа → ввести часть названия → открыть задачу. Ввести то, чего нет, → «Создать задачу».
4. Значок фильтра → «Проекты» → «Новый проект» → название → проект открылся → «Задача в этот проект».
5. В проекте «…» → «Переименовать», затем «Удалить проект» — задачи остались в общем списке.

## Ограничения

Те же, что в сборке 1, кроме экрана задач. «Календарь», «Помощник» и «Кабинет» — следующие сборки.
