# Mark, концепция C — что изменилось относительно пакета B

Основа — пакет B: структура экранов, порядок действий, графит и зелёный, системный шрифт. Ниже только отличия.

## Оформление

| Было в пакете B | Стало в C |
|---|---|
| Карточка главной задачи без рамки, название 17 pt | Тонкая приглушённая зелёная рамка, название 19 pt, без тени |
| Срок жёлтым текстом без пояснения | Единое правило: будущий срок нейтральный, «Срок сегодня» — жёлтая метка со словами, «Просрочено» — красная метка со словами |
| Красного цвета не было | Красный для просроченного, удаления и ошибок |
| Сплошные разделители `#262C32` | Полупрозрачные 7% — список легче |
| «Обсудить план» — контурная капсула | Капсула на фоне карточки с тонкой границей |
| Нижняя панель без отдельной границы | Тонкая граница сверху; иконка «Задачи» с точками |
| Поле названия — текст прямо на листе, всегда на три строки | Заголовок «Новая задача» и отдельное поле с зелёной рамкой фокуса; высота по тексту, до пяти строк |
| «Ближайшее событие» | «Ближайшая встреча» — встречи отделены от задач и в счётчик не входят |
| Название «MARK» | «Mark» везде; новая иконка, экран загрузки и знак на главной |

## Новые экраны и состояния

- Главная: главная задача не выбрана и её выбор; срок задачи прошёл сегодня; загрузка; ошибка получения данных; крупный текст до конца прокрутки.
- Форма: пустая с недоступной «Добавить»; много текста с прокруткой внутри поля; сохранение, ошибка и повтор; черновик.
- Открытая задача, меню задачи, перенос времени с сохранением срока, переименование.
- Удаление даты, крайний срок «до конца дня», напоминание без времени задачи, нет разрешения на уведомления.
- Фильтр «Сегодня», дополнительные фильтры, поиск без результатов, выполненные, корзина с восстановлением.
- Проекты: создание, переименование, удаление с объяснением, смена проекта у задачи.
- Календарь: пустой день, сроки отдельно от расписания, пересечения, изменение времени, конец прокрутки.
- Помощник: ожидание, уточняющий вопрос, обычный ответ, применение с блокировкой, частичный результат, конфликт, нет сети, отмена применённого, пересчёт связанного плана, чаты.
- Вход, регистрация, ошибка входа, восстановление пароля, кабинет и настройки.
- Светлая тема и экран 360 × 780 для основных сценариев.

## Убрано

- Блики, свечение и полоса прогресса из концепции B не используются.
- Кнопки с пометкой «скоро» и будущее распределение задач в интерфейс не включены.
- Разделы и группы заменены одноуровневыми проектами (перенос — `docs/projects-migration.md`).
