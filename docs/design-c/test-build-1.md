# Тестовая сборка 1 — концепция C, основа

21 октября 2026. Первая из нескольких сборок перехода на концепцию C. Работает на обычном аккаунте: меняется только оформление и правила показа, данные на сервере не переносятся и не удаляются.

## Что вошло

- **Название «Mark»** во всех видимых местах: подпись под иконкой, вход, кабинет, помощник, уведомления, виджет, экспорт. Внутренние имена в коде не менялись.
- **Новая иконка** (`design/brand`), **экран загрузки** — зелёный градиент и белый знак, такой же экран внутри приложения до входа.
- **Главная на телефоне по макетам H01–H06**: знак Mark, дата и приветствие, кабинет по аватару; карточка главной задачи с тонкой рамкой и «Сменить»; «Главная задача не выбрана» → «Выбрать»; ближайшее по времени; «План дня · Выполнено N из M» и «Обсудить план»; «С прошлых дней» для не сделанного в запланированный день; плашки «Входящие · N» и «Просрочено · N».
- **Сроки по единому правилу** во всех списках: «Срок сегодня» — жёлтая метка, «Просрочено» — красная, только для прошедшего крайнего срока; будущий срок и время «Когда сделать» — нейтрально; «до конца дня» вместо времени.
- **«Просроченные»** — только прошедший крайний срок. Не сделанное в запланированный день — отдельным списком без красного. «Убрать все» убирает в корзину только просроченные по сроку.
- **«Входящие»** — записанное без проекта и без даты.
- **Короткая форма новой задачи** по макетам C01–C15: заголовок «Новая задача», поле с зелёной рамкой растёт по тексту, «Добавить» недоступна без названия, дата «Сегодня/Завтра», «Ещё» открывает подробную форму с тем же вводом, Enter добавляет.
- **Черновик**: начатая запись сохраняется на телефоне при каждом изменении — название, описание, даты и проект. При следующем открытии «+» черновик возвращается, проект показан плашкой, есть «Удалить черновик». Пустая форма просто закрывается. После добавления черновик очищается.
- **«Задача добавлена · Отменить»** на 5 секунд. Отмена переносит задачу в корзину (решение по «без следа в корзине» ещё не принято).
- **Проект вместо «Раздел и группа»** в подробной форме: один список без разделов и цветов; группы с одинаковыми названиями подписаны разделом; пустые стартовые «Работа», «Личное», «Учёба» скрыты, если в них нет ни одной задачи, в том числе выполненной и в корзине.
- **«Очистить корзину» скрыта**, восстановление осталось.
- Цвета C: рамка главной задачи, лёгкие разделители, круглые отметки и «+», граница нижней панели.

## Что проверить на iPhone

1. Иконка и подпись «Mark» на экране «Домой», экран загрузки при запуске.
2. Главная: выбрать главную задачу, сменить, убрать; отметить выполненной и вернуть.
3. «+» → ввести название → закрыть смахиванием → «Черновик сохранён» → снова «+» — текст на месте → «Удалить черновик».
4. «+» → длинное название в несколько строк — поле растёт, «Добавить» над клавиатурой.
5. «+» → «Без даты» → «Завтра» → «Добавить» → сообщение «Задача добавлена в план на …» → «Отменить».
6. «Ещё» из короткой формы — введённое сохраняется в подробной форме, поле «Проект».
7. Метки «Срок сегодня» и «Просрочено» в главной и в «Задачах».
8. Закрыть приложение с открытой начатой формой и открыть снова — черновик вернётся по «+».

## Ограничения этой сборки

- Экраны «Задачи», «Календарь», «Помощник» и «Кабинет» пока в прежнем виде с новыми цветами и метками — их переоформление в следующих сборках.
- Нет отдельного напоминания у задачи: напоминания по-прежнему приходят за 30 минут до задачи со временем. Отдельное поле напоминания требует изменения сервера.
- Нет кнопки «Готово» при разборе входящих: задача уходит из входящих, когда у неё появляется дата или проект. Отдельный признак разбора — вместе с переносом групп в проекты.
- Встреч как отдельного типа записи нет, поэтому на главной «Ближайшее по времени» — ближайшая задача со временем.
- Окончательное удаление из корзины недоступно до применения и проверки серверной миграции `0014_mark_empty_trash.sql`.
- Сообщения Telegram-бота пока подписаны «MARK» — они меняются выкладкой серверных функций.
- Компьютерная версия не переоформлялась.
