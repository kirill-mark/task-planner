# Mark, концепция C — поведение кнопок и переходов

Файл собирается командой `python3 design/c/export.py`. Первая часть написана вручную и описывает поведение. Вторая собрана из ссылок в самих макетах и совпадает с кликабельным прототипом на холсте. Коды экранов (H01, C03…) — те же, что в названиях досок.

## Главная (H)

| Элемент | Действие |
|---|---|
| Знак Mark | не нажимается |
| Аватар | открывает кабинет (O05) |
| «Сменить» в карточке | лист выбора главной задачи (H03). «Готово» сохраняет выбор, «Отмена» закрывает без изменений |
| Отметка в карточке или строке | выполняет задачу сразу, появляется «Задача выполнена · Отменить» на 5 секунд (H10). Повторное касание отметки возвращает задачу в работу |
| Название задачи | открывает задачу (E01) |
| «Обсудить план» | открывает помощника с вопросом о плане дня (A01) |
| «Входящие · N» | список входящих (T09) |
| «Просрочено · N» | список просроченных (T08) |
| «Выбрать» при невыбранной главной | лист выбора (H03) |
| «Сравнить» в плашке двух версий | экран сравнения (H09). «Оставить эту версию» сохраняет её и удаляет вторую; «Решить позже» закрывает, плашка остаётся |
| «Повторить» при ошибке загрузки | повторяет загрузку (H13) |
| «+» | короткая форма добавления (C01) |

## Создание и редактирование (C, E)

| Элемент | Действие |
|---|---|
| Поле названия | фокус при открытии, клавиатура открыта сразу |
| «Без даты» | лист даты (D01). После выбора капсула показывает дату и выделяется |
| «Напомнить» | лист напоминания (D06 или D07 — в зависимости от наличия времени). Без разрешения на уведомления — D08 |
| «Ещё» | подробная форма (C08) с тем же введённым текстом |
| Плашка проекта «×» (внутри проекта) | убирает проект из новой задачи; подсказка меняется на «Задача попадёт во „Входящие“» |
| «Добавить» | недоступна при пустом названии. Сохраняет задачу, закрывает лист, показывает «Задача добавлена · Отменить» (C13) |
| Смахивание вниз / касание вне листа / «Отмена» | при пустом названии — просто закрыть; при непустом — сохранить черновик (C14) |
| «Черновик · Очистить» | очищает поле, черновик удаляется (C15 → C01) |
| «Повторить» при ошибке | повторяет сохранение (C12 → C11) |
| Строка в открытой задаче (E01) | открывает лист этого поля; «Готово» сохраняет сразу, без общей кнопки «Сохранить» |
| «…» в открытой задаче | меню (E03): выполнить, не делать главной, переименовать, перенести в проект, удалить. «Удалить» переносит в корзину и показывает «Задача удалена · Отменить» |

## Дата и напоминание (D)

| Элемент | Действие |
|---|---|
| «Сегодня», «Завтра» | выбирают дату, лист остаётся открытым до «Готово» |
| «Другая дата…» | месяц (D02). Стрелки листают месяцы; «Вернуться к сегодняшнему дню» — к текущему месяцу |
| «Время» | лист времени (D04). «Без времени» снимает время, длительность остаётся |
| «Убрать дату» | снимает «Когда сделать», проект и статус разбора не меняются (D05) |
| «Открыть настройки iPhone» | открывает настройки уведомлений приложения в iOS |

## Задачи и входящие (T)

| Элемент | Действие |
|---|---|
| Фильтры «Все», «Сегодня», «Входящие» | переключают список, выбранный сохраняется |
| Значок фильтра | лист дополнительных фильтров (T05). «Сбросить» возвращает «Все» |
| Значок слоёв | меню вида (T03): «Списком» или «По проектам». Выбор сохраняется |
| Лупа | поиск (T06) с клавиатурой. Ищет по названиям и описаниям, включая выполненные; результаты появляются по мере ввода. «Отмена» возвращает список с прежней прокруткой |
| «Разобрать» во входящих | лист разбора (T10). «Готово» завершает разбор даже без даты и проекта; «Пропустить» оставляет задачу во входящих; «Удалить» — в корзину |
| «Убрать все в корзину» (просроченные) | подтверждение с числом задач, затем перенос в корзину и «Отменить» |
| «Восстановить» (корзина) | возвращает задачу в общий список с прежними датой и проектом |
| «Очистить корзину» | подтверждение с числом задач и словами «удалятся навсегда». Зависит от серверной функции — см. `scope.md` |

## Проекты (P)

| Элемент | Действие |
|---|---|
| Строка проекта | открывает проект (P04) |
| «Новый проект» | лист создания (P03). «Создать» недоступна при пустом названии |
| «…» в проекте | меню (P09): переименовать (P07), удалить (P08) |
| «Удалить проект» | удаляет только проект, задачи остаются без проекта; «Проект удалён · Отменить» |
| «+» внутри проекта | форма с подставленным проектом (C07) |

## Календарь (K)

| Элемент | Действие |
|---|---|
| День недели | выбирает день; список и шкала меняются |
| Стрелки | предыдущая и следующая неделя |
| Значок календаря | лист месяца (K02); «Сегодня» возвращает к текущему дню |
| Блок на шкале | лист записи (K06): время начала, длительность, дата. «Сохранить» меняет только «Когда сделать» |
| Задача без времени | открывает задачу (E01) |

## Помощник (A)

| Элемент | Действие |
|---|---|
| «Mark» со стрелкой | назад на главную |
| Значок списка | мои чаты и память (A14) |
| Подсказки на первом экране | подставляют текст в поле, не отправляют |
| Микрофон | голосовой ввод (как сейчас); при тексте в поле вместо микрофона — «Отправить» |
| Квадрат во время ответа | останавливает ответ |
| Галочки в предложении | включают и выключают отдельные действия; число на «Применить N» меняется |
| «Применить N» | применяет выбранное, кнопка блокируется до результата (A07) |
| «Отклонить» | закрывает предложение, ничего не меняя |
| «Отменить изменения» | возвращает задачи как были (A12), если их не меняли после применения |
| «Пересчитать план» | отправляет запрос заново с текущими данными (A13) |
| «Повторить» без сети | отправляет сохранённое сообщение |

## Вход и кабинет (O)

|---|---|

| Строки кабинета | открывают соответствующие экраны настроек |
