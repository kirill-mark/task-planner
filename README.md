# План — планировщик задач

Простой локальный планировщик дня/недели на чистых HTML/CSS/JS (без зависимостей и сборки).

## Возможности
- Добавление задач с датой
- Виды «Неделя», «День» и «Все задачи»
- Группы/категории задач с фильтрацией
- Отметка выполнения и прогресс-бары (по дню, по группе, всего)
- Данные хранятся в localStorage браузера

## Запуск

Нужен любой локальный веб-сервер (ES-модули не работают через `file://`):

```bash
cd task-planner
python3 -m http.server 8000
```

Затем открой http://localhost:8000 в браузере.

## Структура
- `index.html` — разметка
- `css/style.css` — стили
- `js/storage.js` — сохранение/загрузка данных (localStorage)
- `js/state.js` — модель данных, CRUD-операции
- `js/dates.js` — работа с датами и неделями
- `js/app.js` — рендер интерфейса и обработка событий
