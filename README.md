# План MARK — планировщик задач

Планировщик дня/недели на чистых HTML/CSS/JS (без зависимостей и сборки), с синхронизацией между устройствами и установкой на телефон как приложение (PWA).

## Возможности
- Разделы → группы → задачи с дедлайнами
- Виды «Список», «Неделя», «День»
- Отметка выполнения и прогресс-бары
- Синхронизация между устройствами в реальном времени (Supabase)
- Устанавливается на телефон как приложение (PWA), работает офлайн

## Запуск

Нужен любой локальный веб-сервер (ES-модули не работают через `file://`):

```bash
cd task-planner
python3 -m http.server 8000
```

Затем открой http://localhost:8000 в браузере.

## Структура
- `index.html` — разметка, подключение manifest и service worker
- `css/style.css` — стили
- `js/storage.js` — сохранение/загрузка данных (localStorage)
- `js/sync.js` — синхронизация с Supabase (облачное хранилище)
- `js/state.js` — модель данных, CRUD-операции
- `js/dates.js` — работа с датами и неделями
- `js/app.js` — рендер интерфейса и обработка событий
- `manifest.json`, `sw.js`, `icons/` — PWA (иконка, офлайн-кеш)
